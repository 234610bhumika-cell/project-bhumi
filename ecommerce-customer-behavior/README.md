# E-Commerce Customer Behavior & Revenue Analysis

**Tools:** SQL, Python, Power BI, Tableau, Excel
**Context:** Deshbandhu College, University of Delhi

## Problem
Understand what drives customer retention and revenue in a large e-commerce
transaction dataset, and identify which customer segments carry the highest churn risk.

## Approach
- Queried and cleaned 50,000+ transaction records using SQL (joins, subqueries,
  window functions) and Python
- Applied predictive modeling techniques to identify purchasing patterns and
  churn indicators
- Built a Power BI dashboard with DAX measures tracking customer lifetime value
  and revenue trends, cross-validated in Tableau for executive reporting

## Key Views
- Retention rate by acquisition channel (referral, paid ads, organic search, etc.)
- Customer lifetime value (CLV) by churn risk segment
- Revenue trend over time, by region

## Key Finding
Identified a **12% higher retention rate among referral-based customers**, informing
retention strategy recommendations.
